# Физическая химия · кинетика

Канонический curated-пакет для тренажёра физической химии. Исходные PDF и презентации
не загружаются в Picrete: в Studio передаётся только этот производный слой с нотацией,
формулами, ограничениями применимости и проверенными типовыми примерами.

Уровень задач из `/Users/doroga/Documents/projects/физха` — `easy` (`Базовый`). Эти
примеры являются шаблонами первого уровня; генератор может менять только входные данные
в разрешённых диапазонах и обязан сохранить тот же физический замысел и вывод.

Пакет содержит пять подтем:

1. Формальная кинетика и метод начальных скоростей.
2. Уравнение Аррениуса и энергия активации.
3. Последовательные реакции первого порядка.
4. Теория столкновений и стерический фактор.
5. Кинетика Михаэлиса–Ментен.

Ключевые номера Ерёмина, включённые в примеры/ориентиры банка: 18-25, 19-4,
19-16; 20-15–20-17, 20-21, 20-22, 20-26, 20-27; 21-15–21-17; 23-2,
23-11–23-19. В текстовых примерах также сохранены четыре типовых задачи из
каждой группы исходной папки.

Для физхимии действует короткая цепочка: Qwen 35B генерирует, DeepSeek V4
независимо проверяет и при ошибке возвращает полную исправленную версию той же
задачи. Отдельный классификатор, второй решатель и предметный критик не вызываются.
Студенческий разбор получает условие и эталон и ведёт к ответу по шагам.
