# Физическая химия · кинетика

Версия R2. Канонический пакет для тренажёра физической химии. Исходные PDF и презентации
не загружаются в Picrete: в Studio передаётся только этот производный слой с нотацией,
формулами, ограничениями применимости и проверенными типовыми примерами.

Уровень задач из `/Users/doroga/Documents/projects/физха` — `easy` (`Базовый`). Эти
примеры являются шаблонами первого уровня; генератор может менять только входные данные
в разрешённых диапазонах и обязан сохранить тот же физический замысел и вывод.
Для остальных задач уровень определяется содержанием: многоточечная регрессия и
сочетание методов — medium, нетривиальные выводы и анализ моделей — hard.

В 11 предоставленных презентациях (343 страницы) кинетики нет. Общие
термодинамические обозначения сверены с ними; кинетика опирается на Ерёмина
и исходные примеры. Карточка PHYS-00 содержит точные границы этого соответствия
и найденную опечатку в уравнении Ленгмюра. Обозначения не объявляются лекционными
там, где соответствующей лекции нет.

Пакет содержит пять подтем:

1. Формальная кинетика и метод начальных скоростей.
2. Уравнение Аррениуса и энергия активации.
3. Последовательные реакции первого порядка.
4. Теория столкновений и стерический фактор.
5. Кинетика Михаэлиса–Ментен.

Ключевые номера Ерёмина, включённые в примеры/ориентиры банка: 18-25, 19-4,
19-16; 20-15–20-17, 20-21, 20-22, 20-26, 20-27; 21-15–21-17; 23-2,
23-11–23-19. В текстовых примерах также сохранены четыре типовых задачи из
каждой группы исходной папки.

Для физхимии действует короткая цепочка: Qwen 35B генерирует, DeepSeek V4
независимо проверяет и при ошибке возвращает полную исправленную версию той же
задачи. Отдельный классификатор, второй решатель и предметный критик не вызываются.
Студенческий разбор и проверка решения на Qwen получают условие и эталон.
Промпт grader относится к работе студента, отдельный verifier — к проверке задачи.
Все четыре промпта написаны вручную и редактируются в Studio.

Для каждой роли отдельно включаются `calculator`, `sympy`, `reference_db` из
предоставленного `essential_skills`. Это инструменты моделей, не дополнительные
верификаторы или фильтры допуска. Генератор вычисляет согласованные данные,
верификатор независимо пересчитывает решение и исправляет ту же задачу;
помощник проверяет обсуждаемый шаг, не раскрывая будущие ответы. Символьное
тождество не доказывает физическую применимость формулы. Ошибка аргументов
инструмента возвращается в тот же диалог для исправления; сетевой сбой не запускает
новую генерацию. Число обращений и расход модели учитываются по всей цепочке.

Код шлюза версионируется в Git. Приватная справочная таблица не входит в публичный
репозиторий и образ: она монтируется отдельно, только для чтения. Доступ к шлюзу
имеет сервер, не браузер студента. Значения из условия имеют приоритет над
справочником; исторические константы сохраняют предупреждения о точности.
Подключение инструментов само по себе не является доказательством качества:
для выпуска нужны тесты вызовов, ручная предметная проверка новых результатов
и проверка поведения помощника на неполных и завершённых решениях.

`blueprints.json` содержит пять предметных блюпринтов с вариантами сложности,
диапазонами модельных параметров и двумя решёнными примерами на подтему. Это
контекст модели, не программный классификатор. Из совместимых параметров сначала
строятся наблюдаемые данные, затем проверяется решение.

Студент разблокирует «Генерировать» после трёх разных решённых задач подтемы
суммарно по уровням; перепубликация не отменяет разблокировку. До этого показана
подсказка «решите 3 задачи». Новые наборы можно запрашивать повторно.

Релиз выполняется из Git через `ops/release_physical_chemistry.py`: производные
карточки, шаблоны, промпты, вручную проверенный банк и публикация. Оригинальные
файлы не загружаются. `reviewed-bank.json` сохраняет идентификаторы текущих задач;
`eryomin-bank.json` добавляет требуемые номера. Ручная проверка отмечается как
ручная с причиной и отпечатком содержимого, не маскируется под проверку DeepSeek.
