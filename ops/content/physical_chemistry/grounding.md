# Физическая химия: каноническая кинетика

Версия curated-слоя: `PHYS-CHEM-KINETICS-2026-09-R1`.

## Общая нотация

Скорость реакции обозначается (v), начальная скорость — (v_0). Концентрации
обозначаются квадратными скобками: ([A]), ([B]), ([S]), ([E]_0). Все
температуры в экспонентах и обратных температурах переводятся в K. Десятичные
значения округляются только в последней строке. Если единицы времени изменены,
единица (k) изменяется согласованно.

Курс использует записи Ерёмина: (r) и (v) — эквивалентные обозначения
скорости только при явном указании соответствия; (K_M), (V_{max}), (E_a),
(A), (k_1), (k_2), (P), (sigma_{AB}), (mu) не переименовываются
молча. Эталонное решение всегда содержит: модель, вывод рабочего уравнения,
подстановку, размерностную проверку, расчёт и физический вывод.

## 1. Формальная кинетика

Общий закон:

[
v=k_{\text{эксп}}[A_1]^{x_1}\cdots[A_n]^{x_n},
\qquad v_0=k_{\text{эфф}}[A]_0^x.
]

Для метода начальных скоростей сравнивают опыты, где неизменны все концентрации,
кроме одной:

[
\frac{v_2}{v_1}=\left(\frac{[A]_2}{[A]_1}\right)^x,
\qquad
x=\frac{\ln(v_2/v_1)}{\ln([A]_2/[A]_1)}.
]

Для (A+B\to P), (v=k[A][B]), ([A]_0=a), ([B]_0=b),
([A]=a-x), ([B]=b-x):

[
kt=\frac{1}{a-b}\ln\frac{(a-x)b}{a(b-x)}
=\frac{1}{[A]_0-[B]_0}
\ln\frac{[A][B]_0}{[A]_0[B]}.
]

Номера Ерёмина: 18-25, 19-4, 19-16. Исходные типовые задачи: `kinetics_topic1_intro_1/2`
и `kinetics_topic1_inter_1/2`. Их уровень — базовый.

## 2. Уравнение Аррениуса

[
k(T)=A\exp\left(-\frac{E_a}{RT}\right),
\qquad
\ln k=\ln A-\frac{E_a}{RT}.
]

Для двух точек:

[
E_a=\frac{RT_1T_2}{T_2-T_1}\ln\frac{k_2}{k_1},
\qquad
A=k_1\exp\left(\frac{E_a}{RT_1}\right).
]

Температуры (T_1,T_2) только в K; (R=8{,}314\ \mathrm{Дж\,моль^{-1}\,К^{-1}})
задаётся в условии или на листе. Формула (k_2/k_1=\gamma^{(T_2-T_1)/10})
допустима только как приближённая эмпирическая оценка, не как замена Аррениуса.
Постоянство (E_a) и (A) — локальное приближение на ограниченном интервале.

Номера Ерёмина: 20-15–20-17, 20-21, 20-22, 20-26, 20-27. Исходные типовые задачи:
`kinetics_topic2_intro_1/2` и `kinetics_topic2_inter_1/2`. Их уровень — базовый.

Для мономолекулярного разложения (A\to B+C) с (k\) в (с^{-1}) нельзя
объяснять температурную зависимость как частоту столкновений (Z\propto T^{1/2})
бимолекулярной реакции. Это сопоставление разрешено только с явной оговоркой
о другой модели.

## 3. Последовательные реакции первого порядка

Для (A\xrightarrow{k_1}B\xrightarrow{k_2}P), ([A]_0=a), ([B]_0=0):

[
[A]=ae^{-k_1t},\qquad
[B]=\frac{ak_1}{k_2-k_1}\left(e^{-k_1t}-e^{-k_2t}\right).
]

Максимум промежуточного вещества находится из (d[B]/dt=0):

[
t_{\max}=\frac{\ln(k_1/k_2)}{k_1-k_2}.
]

Случай (k_1=k_2) требует предельной формы и не смешивается с формулой для
неравных констант. Номера Ерёмина: 21-15–21-17. Исходные типовые задачи:
`kinetics_topic3_inter_1/2` и `kinetics_topic3_intro_1/2`. Уровень — базовый.

## 4. Теория столкновений

Теория столкновений в этом пакете относится к бимолекулярной газовой реакции
(A+B\to P). При заданных эффективных диаметрах:

[
d_{AB}=\frac{d_A+d_B}{2},\qquad \sigma_{AB}=\pi d_{AB}^2,
]

[
\mu=\frac{M_AM_B}{(M_A+M_B)N_A},\qquad
\langle v_{\mathrm{rel}}\rangle=\sqrt{\frac{8k_BT}{\pi\mu}},
]

[
A_{\mathrm{calc}}=N_A\sigma_{AB}\langle v_{\mathrm{rel}}\rangle,
\qquad P=\frac{A_{\mathrm{exp}}}{A_{\mathrm{calc}}}.
]

Величины переводятся в SI до вычислений; (1\ \mathrm{м^3}=10^3\ \mathrm{л}).
Если в условии задан (P), он входит в (A=P A_{\mathrm{calc}}). Не допускается
выводить (T^{1/2}) для мономолекулярной реакции только из того, что она имеет
первый порядок.

Исходные типовые задачи: `kinetics_topic4_intro_1/2` и
`kinetics_topic4_inter_1/2`. Уровень — базовый.

## 5. Михаэлис–Ментен

Механизм:

[
E+S\rightleftarrows ES\xrightarrow{k_2}E+P.
]

При стационарности комплекса:

[
r=v_0=\frac{k_2[E]_0[S]}{K_M+[S]}
=\frac{r_{\max}[S]}{K_M+[S]},
\qquad r_{\max}=k_2[E]_0,
]

[
K_M=\frac{k_2+k_{-1}}{k_1}.
]

Для конкурентного ингибирования:

[
K_M^{\mathrm{app}}=K_M\left(1+\frac{[I]}{K_I}\right),
\qquad
r=\frac{r_{\max}[S]}{K_M^{\mathrm{app}}+[S]}.
]

При ([S]\ll K_M): (r\approx(r_{\max}/K_M)[S]); при ([S]\gg K_M):
(r\approx r_{\max}). Эти пределы называются строгими только при проверке отношения.

Номера Ерёмина: 23-2, 23-11–23-19. Исходные типовые задачи:
`kinetics_topic5_intro_1/2` и `kinetics_topic5_inter_1/2`. Уровень — базовый.
