## Регрессии и приемлемые альтернативы

Для Аррениуса использован невзвешенный МНК ln k против 1/T по всем четырём точкам. R²: 20-26 — 0,9999563393; 20-27 — 0,9999983646.

Для таблиц Михаэлиса–Ментен основной эталон — невзвешенный МНК 1/r против 1/[S]. Это явно определённый метод, воспроизводящий округлённые ответы задачника. В исходном тексте метод не задан, поэтому другой обоснованный метод обработки не следует считать ошибкой только из-за несовпадения последних цифр.

Альтернативный МНК исходных скоростей проверен локальным одномерным поиском по положительному K_M: при фиксированном K_M положим fᵢ = Sᵢ/(K_M+Sᵢ), оптимальное r_max = Σfᵢrᵢ/Σfᵢ², затем минимизируем Σ(rᵢ−r_max fᵢ)² по ln K_M. Он иначе взвешивает исходные ошибки и потому даёт несколько другие значения.
